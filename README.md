# titanic-data-visualization
Exploratory data visualization of the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn.


# Titanic Data Visualization

## Overview
This project explores the famous Titanic dataset using Python data visualization libraries. It was created as a hands-on learning exercise to practice exploring data, identifying patterns, and comparing passenger characteristics and survival rates.

## Objectives
- Explore the dataset and inspect missing values.
- Visualize the distribution of passenger ages and ticket fares.
- Explore relationships between age, fare, and survival.
- Compare survival rates by gender, passenger class, age group, and embarkation port.
- Examine correlations between numerical variables.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations
The notebook includes:
- Histograms
- Scatter plots
- Bar plots
- Count plots
- Correlation heatmap
- Box plots
- Point plots
- Subplots for comparing distributions

## Dataset
The Titanic dataset is loaded directly from Seaborn using `sns.load_dataset('titanic')`.

## How to Run
1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install numpy pandas matplotlib seaborn jupyter
   ```

3. Open the notebook:

   ```bash
   jupyter notebook
   ```

4. Run the cells to explore the visualizations.
